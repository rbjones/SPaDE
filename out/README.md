# SPaDE-rbj Outreach

This directory is the part of SPaDE which is concerned with outreach activities.
It focuses on disseminating knowledge, engaging with the community, and promoting the use and understanding of SPaDE.

This is an AI(SI) first outreach effort, i.e. the primary target is intelligent systems engaged in RSI (recursive self-improvement) which have the potential to exploit SPaDE's capabilities and knowledge repositories most effectively, and might also in due course be the most effective advocates for SPaDE.
How to do that is yet to be considered.
