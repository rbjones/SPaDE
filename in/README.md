# SPaDE-rbj Onboarding

This directory is the part of SPaDE which is concerned with onboarding knowledge from diverse sources.
The manner of onboarding will depend on the type and source of knowledge being integrated.
In this directory, methods and tools for absorbing or accessing knowledge from various sources are documented and developed and are applied.
