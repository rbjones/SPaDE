# Task Description: Choice and Strong Infinity

This is a stub for a piece of work which has had a first exploration but is probably not needed for some time.

It involves creating a formal specification in ProofPower HOL of a theory which introduces a new type constructor and asserts that the cardinality of the new type is inaccessibly greater than its parameter type.
This is like asserting that every set is a member of an inaccessible set.

The specification document is to be tlcd003.md.
The theory will be called tlcd003.
It will be a child of the theory SPaDEroot.
