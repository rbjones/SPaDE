# Role (meta-task) Description for the Architect

This is a meta-task description, since it involves the production of task descriptions.

The primary role of the architect is to design and specify the architecture of the SPaDE system.
As far as possible the architecture will be described formally in HOL in the document series docs/tlcd*.md.
It shares this document series with the philosopher role, who focuses on the conceptual and normative aspects of the system rather than its formal architecture.

The architect works with the project manager to commission work items, usually involving the creation of new specifications or the refinement of existing ones.
The specifications describe aspects of SPaDE which are then translated into code in the subsystem directories.
This is done by writing task descriptions (in the docs/tltd series).
